# Arquitetura de marcas

## 1. TCG Tactical Database

Projeto de produto independente, com voz institucional e foco em dados, evidências competitivas, construção de decks e ferramentas táticas.

Nome de trabalho:

```text
TCG TACTICAL DATABASE
```

Assinaturas permitidas:

```text
TCG // TACTICAL DATABASE
TACTICAL DECK SYSTEM
DATABASE // DECK LINK MAP
```

Não usar no produto:

- Potter, CraZyWiZ ou qualquer identidade pessoal;
- rosto, mascote ou callsign do apresentador;
- “by Potter”, “Potter presents” ou lockup conjunto;
- links obrigatórios para canal ou Patreon;
- linguagem em primeira pessoa atribuída ao criador.

O produto pode começar especializado em Gundam Card Game sem incorporar “Gundam” à marca principal. Isso permite descrever honestamente o conteúdo atual e mantém aberta a expansão futura para outros TCGs.

## 2. POTTER

Marca pessoal de mídia para YouTube, Twitch, Patreon, comunidade, gameplay, unboxings e opinião.

POTTER pode citar, demonstrar ou avaliar o TCG Tactical Database editorialmente. Essa relação não deve virar co-branding nem sugerir que a identidade do produto depende da personalidade do canal.

## 3. Fronteira operacional

| Elemento | TCG Tactical Database | POTTER |
| --- | --- | --- |
| Site e ferramentas | Sim | Não |
| Database e Deck System | Sim | Não |
| YouTube, Twitch e Patreon | Não | Sim |
| Rosto e mascote | Não | Sim |
| Voz | Institucional | Pessoal |
| Logo e handles | Próprios | Próprios |
| Divulgação cruzada | Citação editorial | Citação editorial |

## 4. Nome e propriedade intelectual

`TCG Tactical Database` é um nome de trabalho mais neutro do que opções que incorporam diretamente “Gundam” ou “Mobile Suit”. Isso reduz dependência nominal de uma franquia, mas não constitui liberação jurídica nem garante exclusividade de marca.

Antes de registrar domínio, perfis ou marca, fazer busca de anterioridade no INPI e na Global Brand Database da WIPO, incluindo variações fonéticas e as classes aplicáveis a software, bases de dados e entretenimento.
